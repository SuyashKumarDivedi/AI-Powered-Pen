# AI Powered Pen 🖊️🤖

AI Powered Pen is an innovative project that combines **artificial intelligence** with writing tools.  
It is designed to help users write smarter by suggesting words, correcting grammar, and even generating creative content in real time.  

---

## ✨ Features
- Smart word predictions  
- Real-time grammar and spelling corrections  
- Context-aware suggestions  
- Creative content generation  
- Easy-to-use interface  

---

## 🛠️ Technologies Used
- **HTML5**
